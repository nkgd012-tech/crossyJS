# crossyJS for gb300 ( may run on sf2000) 
A Crossy Road-style game rewritten in JavaScript for the GB300; use the `mquickjs` core created by `sajnaps` (synaps33) to play it. ( only for FrogUI )

* The graphics are strictly 2D, not pseudo-3D like in a real game.
